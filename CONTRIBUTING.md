# Contribuir

Use Python 3.12 e o ambiente venv ou Conda descrito no README.
Não envie senhas, .env, bancos locais ou arquivos de clientes ao Git.
As migrações antigas são necessárias para atualizar bancos existentes: não remova.
Ao alterar modelos, crie a migração com manage.py makemigrations.
Execute os testes conforme o README antes de enviar alterações.
